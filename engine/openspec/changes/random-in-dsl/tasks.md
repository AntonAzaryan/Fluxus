## 1. Действие random (ACT-1, RNG-6)

- [ ] 1.1 `random { as, kind?, bound?, subStream?, do }` в таблице действий `src/actions.ts`
- [ ] 1.2 `kind: fixed` — `nextFixed()`; `kind: below` — `nextBelow(toInt(bound))`
- [ ] 1.3 `subStream` — строковый литерал, стрим по RNG-7; по умолчанию основной стрим системы
- [ ] 1.4 `as` вводит имя только в тело `do` — та же семантика, что у `let` и `forEach`

## 2. Валидация (SYS-3)

- [ ] 2.1 `as` и `subStream` — литералы; `bound` — выражение; `do` — список действий
- [ ] 2.2 `kind: below` без `bound` — ошибка на регистрации, а не при первом срабатывании
- [ ] 2.3 Неизвестный `kind` — ошибка с перечислением допустимых

## 3. Схемы (SER-5)

- [ ] 3.1 `system.schema.json` и `scene.schema.json` перегенерированы из `actionNames`
- [ ] 3.2 Тест сверки закоммиченных схем зелёный

## 4. Тесты и эталоны

- [ ] 4.1 Одинаковый seed → одинаковая последовательность; разный seed → разная
- [ ] 4.2 Суб-стрим независим: добавление вызова в одну ветку не сдвигает другую (RNG-2)
- [ ] 4.3 Распределение `below` не смещено на границах — сверка с прямым `nextBelow`
- [ ] 4.4 Golden-сценарий со случайным разбросом; поле `rng` в снапшотах непустое
- [ ] 4.5 Восстановление снапшота продолжает ту же последовательность (RNG-5)
