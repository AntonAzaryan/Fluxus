## 1. Разбиение RenderHost (render-ts, без воркера)

- [x] 1.1 Выделить из `RenderHost` Extractor: `onTick`-половина (обход сущностей, `kindOf`+кэш, конверсия Q16.16→float, `FloorMirror`, capture aim) с выходом в плоскую форму `TickView`
- [x] 1.2 Выделить ViewBuffer: main-половина (prev/curr-скольжение, snap/teleport-порог, протухание aim, `frame(alpha)`), вход — плоская форма
- [x] 1.3 Собрать однопоточный `RenderHost` как Extractor→ViewBuffer прямым вызовом; существующие тесты и демо проходят без правок подсистем (SHELL-2)
- [x] 1.4 Тест эквивалентности: прогон сценария через старый путь и через пару Extractor/ViewBuffer даёт идентичный `TickView` на каждом тике

## 2. Формат буфера (render-ts или client-ts, общий модуль писателя/читателя)

- [x] 2.1 Раскладка: заголовок (версия, tick, mode, флаги, счётчики), SoA-колонки сущностей (id как u32×2, kind-индекс, x/y/yaw f32, level/флаги, aimYaw), дельта пола (design Decision 3)
- [x] 2.2 Писатель (из плоской `TickView`) и читатель (в плоскую `TickView`) в одном модуле; roundtrip-тест писатель→читатель в одном потоке против прямого вызова (SHELL-3)
- [x] 2.3 Перевыделение буфера с запасом при росте сцены; тест: рост числа сущностей не аллоцирует на каждом тике

## 3. Пакет client-ts: воркер-хост и канал

- [x] 3.1 Каркас `engine/client-ts` (`@game-mvp/client`) в workspace: worker-entry (тикер с коррекцией дрейфа, `Simulation`, Extractor) и main-обвязка (приём конверта, возврат буфера, ViewBuffer)
- [x] 3.2 Handshake: конфиг сцены, terrain grid, таблица kind'ов, `tickSeconds` одним сообщением до первой доставки (SHELL-5)
- [x] 3.3 Ping-pong с ack-conflation: пул буферов, отправка только при наличии свободного буфера, staging-перезапись в воркере (SHELL-3, SHELL-4, design Decision 5)
- [x] 3.4 Reliable-события: аккумулятор с номерами тиков между доставками, лимит глубины с пометкой «просрочено» (SHELL-4, Risks)
- [x] 3.5 Обратный канал: ввод (сбор в main, применение как `InputFrame` на границе тика) и команды WSM pause/rewind/seek/resume (SHELL-6)
- [x] 3.6 Часы: `lastTickAtMs` по моменту доставки, кламп альфы; флаги разрыва (snapAll/isReplay) через заголовок буфера (SHELL-7)
