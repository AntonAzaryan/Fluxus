# Conventions

Правила написания логики систем и операций.

## 1. Детерминизм

Вся логика ядра должна быть детерминированной:
- Никаких вызовов `Date.now()`, `Math.random()`, системного времени
- Никакого I/O (сеть, файлы, база данных)
- Никаких глобальных переменных вне ECS
- Порядок итерации сущностей — строго по возрастанию `entity_id`

## 2. Fixed-point арифметика

- Запрещено использование `f32`/`f64` в логике симуляции
- Все числовые значения хранятся как `i32` с масштабом из `meta.fixed_point_scale`
- Пример: `fixed_point_scale = 1000` → `1.5` хранится как `1500`

## 3. RNG

- Любой рандом только через ресурс `RngState`
- Каждая операция рандома продвигает счётчик в `RngState`
- Формула: `seed = (seed * 1103515245 + 12345) & 0x7fffffff`

## 4. Время

- Время только через ресурс `TimeState`
- `dt = (1 / tick_rate) * time_scale`
- Замедление времени = изменение `time_scale`, не пропуск систем

## 5. События

- Команды игрока обязаны иметь поля `tick` и `player_id`
- Внутренние события потребляются в том же тике, что порождены
- Порядок событий — порядок поступления в буфер

## 6. Чистота систем

Каждая система — чистая функция:
```
system_output = system(components, resources, events)
```
- Никакого скрытого состояния между тиками
- Никаких сайд-эффектов вне ECS
