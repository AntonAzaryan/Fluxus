# Глоссарий

Словарь терминов для спецификации игрового ядра.

## Термины

| Термин (RU) | Термин (EN) | Определение |
|-------------|-------------|-------------|
| Тик | Tick | Базовая единица времени симуляции (1/60 секунды при tick_rate=60) |
| Сущность | Entity | Уникальный идентификатор в ECS, носитель компонентов |
| Компонент | Component | Атомарные данные, крепящиеся к сущности |
| Система | System | Логика, обрабатывающая компоненты |
| Архетип | Archetype | Шаблон композиции компонентов для спавна сущностей |
| Ресурс | Resource | Глобальное состояние симуляции, не привязанное к сущностям |
| Событие | Event | Команда или нотификация, передаваемая между системами |
| Rollback | Rollback | Механизм отката состояния к предыдущему снапшоту |
| Lockstep | Lockstep | Режим синхронизации, где все клиенты выполняют одинаковые тики |
| Fixed-point | Fixed-point | Представление чисел как i32 с масштабом (избегание float) |
