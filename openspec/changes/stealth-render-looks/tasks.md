# Tasks: stealth-render-looks

Порядок — по зависимостям: 1 — данные и порт без картинки (стелс-слой ещё не рисуется, но политика и пробег доли уже проверяемы), 2 — подсистема и проход сцены, 3 — ярусы, 4 — интеграция потребителей и качество, 5 — сквозные проверки. Задачи **[вручную]** требуют браузера на арене.

## 1. Секция, порт и поле вида на записи

- [ ] 1.1 `engine/assets-ts/src/presentation.ts`: новая форма секции `stealth` (FOW-13) — подсекции `hidden`/`revealed` с закрытыми ключами `opacity`, `refraction`, `rim`, `rimColor`, `reflection` и границами, `transitionSeconds ≥ 0`; прежние ключи отвергаются как неизвестные; тесты в `presentation.test.ts` на принятие, адресный отказ по каждому ключу и на `allyOpacity`
- [ ] 1.2 `engine/render-ts/src/subsystems/models/instanceRecord.ts`: поле вида на записи (целевой вид, целевая доля, нарисованная доля, флаг «на слое стелса») и его сброс при переиспользовании записи; тест: новая запись — вид отсутствует, доля ноль
- [ ] 1.3 `subsystems/models.ts`: порт `setStealthLook(entity, look | null, target)` по образцу `setTint`, экспорт типа порта из `index.ts`; без опции `StealthMaterials` порт отвечает `false`; тест на отказ без записи и без порта
- [ ] 1.4 `subsystems/models/instanceStealth.ts`: пробег нарисованной доли к цели со скоростью `1 / transitionSeconds` по модулю часов (как `advanceFade`), снап при `snapAll`; тесты: вход, смена вида без скачка, обратный ход мира не разворачивает, разрыв ставит в цель

## 2. Подсистема стелса и проход сцены

- [ ] 2.1 Порт `ScenePass` в `types.ts` (нейтральный модуль, REND-8) с умолчанием «прямой `renderer.render`»; `postprocess/chain.ts` и `fog/frameTarget.ts` принимают его опцией и зовут вместо своего `renderer.render`; тесты обоих владельцев на вызов порта ровно один раз за кадр
- [ ] 2.2 `subsystems/stealth.ts`: контракт REND-8, чтение секции `stealth` с умолчаниями FOW-13 и обновление в рантайме (ED-15), uniform-держатели параметров видов; тест: секции нет — умолчания, правка секции меняет держатели без пересборки
- [ ] 2.3 Реализация `ScenePass` подсистемой (design 3): вызов 1 без слоя стелса; при ненулевом числе записей на слое — копия и вызов 2 с `autoClear = false`, `shadowMap.autoUpdate = false`, слои камеры восстановлены; без записей вызов 2 не делается; тесты на число вызовов рендера и восстановление флагов
- [ ] 2.4 Копия цвета (design 4): `grabTarget` размера `кадр × min(1, grabScale)` через `own('renderTarget', 'stealth', …)`, blit-материал; путь с целью — из `target.texture`, путь канваса — `copyFramebufferToTexture` в `FramebufferTexture` и blit; пересборка цели событием (смена размера, ручки), не кадром; тесты: размер цели по ручке, ноль целей в кадре без стелса, освобождение в `dispose`
- [ ] 2.5 Ручки `stealth.refraction` и `stealth.grabScale` в реестре (QUAL-1); тесты: выключенное преломление — копия не снимается; неизвестная ручка владельца `stealth` отвергается адресно
- [ ] 2.6 Счётчики `stealthGrabs`, `stealthInstances` в `cost.ts` (секция `frame`) и учёт ресурсов в `footprint.ts`; тест: кадр без стелса — оба нулевые

## 3. Текст затенения и ярусы

- [ ] 3.1 `model/stealthShader.ts`: патч `onBeforeCompile` фрагментного стейджа `MeshStandardMaterial` (design 5) — преломление по копии, кромка, отражение, произведение с fade и тинтом, ветка без преломления; `customProgramCacheKey`; тест на состав uniform'ов и на то, что патч применим к обоим хостам
- [ ] 3.2 Порт `StealthMaterials` (нейтральный модуль): «материал вида для VAT-хоста», «копия вида для базового материала», держатели uniform'ов; подсистема стелса реализует, подсистема моделей принимает опцией сборки; тест сборки без порта — сцена собирается, порт вида бездействует
- [ ] 3.3 `model/batch.ts`: параллельные стелс-части на уровень (design 6) — слой стелса, `castShadow = false`, свои буферы, атрибут `instanceStealth` в `OWNED_ATTRIBUTES`; компактация раскладывает записи по нарисованной доле; `visible` стелс-части только при `count > 0`; тесты: запись с долей уезжает из базовой части в стелс-часть и обратно, счёт draw-объектов без невидимок прежний, `dispose` освобождает атрибут
- [ ] 3.4 `subsystems/models/carrier/batched.ts`: носитель пишет вид и долю записи в буферы стелс-части; тест на значения атрибута
- [ ] 3.5 `subsystems/models/instanceFade.ts` → общий держатель подмен материалов (design 7): стек оригинал → fade-копия → стелс-копия, fade-доля множителем в верхнюю; пул стелс-копий на запись; меши на слое стелса при доле > 0; тесты: «fade во время стелса», «стелс во время fade», «снятие обоих» возвращают оригинал ровно один раз; соседи по разделяемому материалу не тронуты
- [ ] 3.6 `guard.test.ts`, `lifetime.test.ts`, `steadyState.test.ts`: новые ресурсы подсистемы под `own(…)`, ноль живых после сноса, стационарность при обороте невидимок; тесты зелёные
