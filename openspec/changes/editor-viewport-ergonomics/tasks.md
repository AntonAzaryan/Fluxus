## 1. Кадрирование в конвейере камеры (CAM-8)

- [x] 1.1 `engine/render-ts/src/camera/rig.ts`: вход кадрирования у `CameraRig` — прямоугольник в мировых координатах, пропорции кадра и признак мгновенного применения; результат ложится в точку наблюдения и желаемую дистанцию, а не в отдельное состояние
- [x] 1.2 Там же: дистанция считается из полуразмеров прямоугольника, `config.fovDeg`, `config.pitch` и поданных пропорций; ограничивающим берётся тот из двух габаритов, который упирается первым
- [x] 1.3 Там же: кламп дистанции по `minDistance`/`maxDistance` (CAM-4) и точки наблюдения по инжектированным границам с `boundsMargin` (CAM-3); поданный прямоугольник инжектированные границы не подменяет (CAM-7)
- [x] 1.4 Там же: мгновенное применение выставляет и сглаженную дистанцию, и желаемую (иначе первый кадр всё равно приезжает); сглаженное — только желаемую, а доводит её обычное сглаживание `zoomSmoothing`
- [x] 1.5 Там же: в `fly` кадрирование меняет наземные величины и не трогает `modeState`, `flyX/flyY/flyZ`, `flyYaw/flyPitch` (CAM-8, CAM-2)
- [x] 1.6 `engine/render-ts/src/index.ts`: вход кадрирования экспортируется вместе с остальным API камеры
- [x] 1.7 `engine/render-ts/test/camera.test.ts`: headless-тесты (CAM-1) — прямоугольник помещается в кадр при разных пропорциях; кламп на большом прямоугольнике не даёт отказа; после кадрирования панорама и зум работают, и следующий кадр к прямоугольнику не возвращается; кадрирование в `fly` не меняет режима; мгновенное применение даёт нужную дистанцию на первом же `update`
