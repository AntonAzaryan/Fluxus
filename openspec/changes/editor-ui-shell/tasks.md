- [ ] 1.1 `openspec/specs/editor/spec.md`: ED-22 «Визуальный язык интерфейса» — Material Design в тёмной ахроматической базе, единственный лавовый акцент за интерактивным состоянием, запрет различать состояния валидации только оттенком, запрет окрашивать вьюпорт хромом, плотность под таблицы полей; три сценария
- [ ] 1.2 Там же: ED-23 «Каркас рабочих областей» — одно окно, переключение горячей клавишей, объекты и системы разными областями, сохранение состояния области, сквозные выделение/история/поиск, отстыковка как удобство хоста и не условие операции; три сценария
- [ ] 1.3 Там же: ED-24 «Скелет рабочей области» — навигатор/поверхность/инспектор в неизменном порядке, палитра команд и поиск по проекту, инспектор из схемы; три сценария
- [ ] 1.4 Там же: ED-25 «Расширяемость через реестры вкладов» — регистрация вклада без правки зарегистрированного, запрет доменных имён в каркасе; три сценария
- [ ] 1.5 Там же: ED-26 «Аффорданс превью и индикация режима» — запуск из любой области без сохранения на диск, постоянная видимость режима, видимая недоступность операций в превью; два сценария
- [ ] 1.6 Там же: ED-27 «Строковые ресурсы и локали» — весь текст из ресурсов, `ru`/`en` равноправны, переключение без перезапуска, локаль не влияет на документы, идентификаторы не локализуются, локаль — настройка пользователя; два сценария
- [ ] 1.7 Там же: ED-28 «Подсказки к полям» — ключ вычисляется из пути схемы, запрет ручной таблицы соответствий, цепочка локаль → `en` → ключ, запрет пустой подсказки, двусторонний отчёт (недостающие и осиротевшие), обнаружимость устаревшего перевода; четыре сценария
- [ ] 1.8 Там же: ED-29 «Слой операций авторинга» — всякая правка операцией, запрет записи мимо слоя, исполнимость без интерфейса, совпадение наборов операций, устойчивая адресация; три сценария
- [ ] 1.9 Там же: ED-30 «Само-описание и структурная валидация» — машинный каталог из тех же реестров, описания ED-28 как описания каталога, структурный результат валидации; три сценария
