## 2. Сервер матча (engine/net-ts)

- [ ] 2.1 Аренда слота в `running` (design D1): разрыв отвязывает соединение от слота, не освобождая слот ростера; `Hello` владельца ростера на отвязанный слот проходит полный хендшейк (NTR-5) и получает `Welcome` + повторный `Start` с исходным тиком старта; возобновляются персональные снапшоты (NTR-17). Проверка: unit-тест matchServer — разрыв → реконнект → клиент получает `Welcome`, `Start`, снапшоты текущих тиков.
- [ ] 2.2 Отказы: `Hello` не из ростера после `Start` → именованный `Reject`; `Hello` владельца на слот с живым владельцем → `Reject slot-taken` (NTR-6, NTR-17). Проверка: unit-тесты обоих отказов.
- [ ] 2.3 Заместитель (NTR-18): приём `role: 'substitute'` только в `running` и только на отвязанный слот, иначе `Reject` (до `Start` — именованный отказ, занятый слот — `slot-taken`); слот с заместителем не копит молчание; `Hello` владельца вытесняет заместителя — `Reject displaced-by-owner` + закрытие, владелец входит реконнектом, ввод вытесненного отбрасывается проверкой слота. Проверка: unit-тесты — посадка, вытеснение без тика с двумя арендаторами, отказ на занятый слот, отказ до старта.
- [ ] 2.4 `Bye` в `running` = отвязка, а не `end('player-left')` (design D4): дальше порог молчания. Переписать тесты, ожидавшие мгновенный `End`. Проверка: тест — после `Bye` матч жив, `End` приходит по порогу молчания.
- [ ] 2.5 Поток `Events` при реаттаче открывается заново (design D6): кольцо повторов слота сбрасывается, первый диапазон после реаттача не пересекает доставленное до разрыва (NTR-17 — свежий курсор без дублей и без роста счётчика разрывов). Проверка: unit-тест — короткий разрыв → реаттач → нет пересечения диапазонов, клиент не проигрывает событие дважды.
- [ ] 2.6 Порог молчания как окно возврата: убедиться, что `silentTicks` слота сбрасывается при посадке живого соединения (владельца или заместителя) и продолжает копиться на отвязанном слоте (NTR-6). Проверка: unit-тест — возврат на границе порога не завершает матч; невозврат завершает `End` с названным исходом.
