# Tasks: sec03-sim-systems-spec-alignment

Требования — `specs/fog-of-war/spec.md` (**FOW-1**, **FOW-5**) и `specs/terrain/spec.md` (**TERR-7**),
разбор решений — design.md (D1–D4). Гейт один и он локальный: `npm run check` из корня репозитория (CI нет).

Изменение заводилось по факту сделанной работы: валидация спек против кода
(`docs/reviews/spec-validation-2026-09-01/03-sim-systems.md`) назвала все пять расхождений; два чинятся
кодом вместе с текстом требования, три — текстом.

## 1. Дельты требований (D1, D2, D3)

- [x] 1.1 `specs/fog-of-war/spec.md`: MODIFIED FOW-5 — названа вторая дверь запрета: сборка, которой
      документ прогона включил пересчёт видимости в мире с объявленным `Visibility` и без террейна,
      отвергается до первого тика с указанием недостающего террейна; прогон в сцене без компонентов
      видимости ошибкой не является. Новые сценарии: «Документ прогона включил пересчёт видимости в сцене
      без террейна», «Пересчёт включён в сцене без компонентов видимости». Блок MODIFIED несёт требование
      ЦЕЛИКОМ со всеми действующими сценариями: MODIFIED заменяет блок, и опущенный сценарий архивация
      молча выкинула бы.
- [x] 1.2 Там же: MODIFIED FOW-1 — обоснование предела радиуса обзора приведено к правде: предел приходит
      от `raycast` (PHYS-6), арифметика отбора кандидатов нормируется QUERY-1 и собственного предела
      обзору не назначает, а действует более строгий из двух запросов. Сценарий «Радиус обзора у предела»
      перестал приписывать некорректный результат обоим запросам.
- [x] 1.3 `specs/terrain/spec.md`: MODIFIED TERR-7 — ширина рампы нормирована поперёк подъёма, названы
      ось подъёма, правило ширины и обе вырожденные конфигурации (угловая рампа, флаг на ровном месте).
      Новые сценарии: «Две клетки-рампы друг за другом по подъёму», «Угловая рампа».
- [x] 1.4 Перенести дельты в `openspec/specs/fog-of-war/spec.md` и `openspec/specs/terrain/spec.md`.
      Изменение при этом НЕ архивируется: оно остаётся в очереди как запись о принятом решении. Проверка —
      `npx openspec validate --specs --strict` и `npm run spec-graph -- check`.

- [x] 3.4 `engine/core-ts/test/filter.test.ts`: стенд REW-11 отдаёт сборке террейн своей же сцены — до
