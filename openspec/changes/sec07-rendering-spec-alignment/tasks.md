## 2. Дельты требований (D5, D6)

- [x] 2.1 `specs/rendering/spec.md`: MODIFIED REND-30 — абзац о составе авторских параметров теней: режим, сторона карты теней, доля статики; семантика доли, её умолчание и режимы, в которых она не применяется.
