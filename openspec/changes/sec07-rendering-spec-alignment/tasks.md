## 2. Дельты требований (D5, D6)

- [x] 2.1 `specs/rendering/spec.md`: MODIFIED REND-30 — абзац о составе авторских параметров теней: режим, сторона карты теней, доля статики; семантика доли, её умолчание и режимы, в которых она не применяется. Блок MODIFIED несёт требование ЦЕЛИКОМ со всеми действующими сценариями: MODIFIED заменяет блок, и опущенный сценарий архивация молча выкинула бы.

## 5. Доводка по независимому ревью

- [x] 5.1 REND-1, сценарий «Подсистема тумана берёт рендерер»: «прочим подсистемам он не достаётся» отбирало порт у пост-обработки (REND-34) в том же требовании, которое правилом ей его выдаёт. Условие переписано на «подсистеме без собственного прохода кадра он не достаётся»; оба сценария про порт оставлены — новый нормирует правило, старый остаётся случаем тумана.

- [x] 5.3 REND-30: три поля названы ключами документа (`shadows.mode`, `shadows.mapSize`, `shadows.staticShare`) и подсекцией, в которой живут, — как REND-29 (`hemisphere`, `rim`) и REND-34 (`toneMapping`, `bloom`, `lut`).
