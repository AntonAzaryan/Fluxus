# Tasks: sec06-netcode-spec-alignment

Требования — `specs/netcode/spec.md` (**NET-2**, **NET-4**, **NET-5**, **NET-17**) и `specs/netcode-transport/spec.md` (**NTR-5**, **NTR-10**), разбор решений — design.md (D1–D6). Гейт локальный: `npm run check` из корня (CI нет); в этом изменении кода нет, поэтому достаточной проверкой является `npx openspec validate --specs --strict` вместе с `npm run spec-graph -- check`.

Изменение заводится по факту сделанной работы: валидация спек против кода (`docs/reviews/spec-validation-2026-09-01/06-netcode.md`) назвала все пять расхождений, и все пять чинятся текстом требования, а не кодом.

## 1. Дельты требований (D1–D5)

- [x] 1.1 `specs/netcode/spec.md`: MODIFIED NET-2 — блок «Область действия»: NET-2, NET-4 и NET-5 нормируют режим с предсказанием и вступают в силу вместе с ним, до тех пор действует NTR-10; переход — включение слоя, а не смена протокола. Новый сценарий «Предсказание ещё не включено». Блок MODIFIED несёт требование ЦЕЛИКОМ со всеми действующими сценариями: MODIFIED заменяет блок, и опущенный сценарий архивация молча выкинула бы.
- [x] 1.2 Там же: MODIFIED NET-4 и NET-5 — по фразе, относящей требование к области действия NET-2.
- [x] 1.3 Там же: MODIFIED NET-17 — правило нормализации умолчаний переписано через нейтральное значение типа поля (ECS-3, ECS-6); умолчание `0` у поля-ссылки объявлено значимым. Новый сценарий «Нулевое умолчание у поля-ссылки».
- [x] 1.4 `specs/netcode-transport/spec.md`: MODIFIED NTR-5 — порядок двух сверок по сторонам (сервер до `Welcome`, клиент на `Welcome`, до первого кадра ввода и до первого применённого снапшота), снапшот прежде `Welcome` — ошибка протокола, ожидания подтверждения от клиента нет и завести его нельзя (NTR-4). Сценарий «Версии совпали, ассеты разошлись» переписан, добавлен «Сервер начал матч, пока клиент собирал свой мир».
- [x] 1.5 Там же: MODIFIED NTR-10 — запрет на `tick()` условен нормативно («пока предсказание не включено»), плюс блок «Оценка серверного тика» с верхней границей `snapshotTick + tickRate / snapshotRate + inputDelay` и с запретом зависеть от `lead` и от транспортного RTT. Новый сценарий «Часы клиента идут быстрее серверных».

## 2. Правка вне требований (D6)

- [x] 2.1 `openspec/specs/netcode-transport/spec.md`, блок `## Open Questions`: снять запись «Компенсация половины круга в оценке серверного тика» (названа в `## Notes` дельты). Две другие записи блока остаются.

- [x] 2.2 `openspec/changes/net-handshake-wire-truth/specs/netcode-transport/spec.md`: блок MODIFIED NTR-5 неархивированного изменения приведён к синхронизированному тексту требования. MODIFIED заменяет блок целиком, поэтому отставшая дельта откатила бы эту правку в момент своей архивации — молча и задним числом.
