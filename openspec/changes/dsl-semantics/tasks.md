## 2. Приведение evaluator'а к таблице

- [x] 2.1 `expr.ts`, `==`/`!=`: разнотипные операнды (`number` против `bool`) — ошибка вычисления, называющая оператор и полученные типы, а не `false` (EXPR-8, EXPR-7). Сравнение с `vec2` остаётся ошибкой как сейчас
- [x] 2.2 Тесты краевых случаев, нормированных впервые: `clamp` при `lo > hi` даёт `hi`; `vec.normalize` нулевого вектора даёт нулевой вектор; `abs` от `INT32_MIN` даёт `INT32_MIN`; `{"tick": null}` отвергается по арности, `{"tick": []}` работает
- [x] 2.3 Тесты ленивости: `and` с `false` первым и заведомо падающим выражением вторым не падает; то же зеркально для `or`; невыбранная ветвь `if` и условия за первым истинным не вычисляются
- [x] 2.4 Тест на отсутствующее: `{"+": [a, b, c]}`, унарный `-`, `var` с двумя аргументами, цепочечное `<` с тремя аргументами, `if` из двух аргументов — каждое отвергается (EXPR-8, раздел «Чего в таблице нет»)
