## 3. Тесты ядра

- [ ] 3.1 Порядок ID: сцена с террейном и ареной плюс `initial` из трёх записей — носители получают первые `index`, расставленные идут за ними в порядке списка
- [ ] 3.2 Перестановка двух записей меняет `index` местами и меняет `worldInitHash`; добавление `arena` к сцене с непустым `initial` сдвигает `index` расставленного на один
- [ ] 3.3 Сложение расстановок: сценарий с непустым `initial` над сценой с непустым `initial` даёт сумму, сначала записи сцены; замещения нет
- [ ] 3.4 Хеши: правка `initial` меняет `worldInitHash` и не меняет `contentPackHash`; отсутствующий и пустой `initial` дают один и тот же мир и один и тот же хеш
- [ ] 3.5 Ошибки загрузки: неизвестный prefab, компонент вне prefab'а (CMD-6), поле вне схемы — каждая падает на `loadScene` с ошибкой, называющей имя
- [ ] 3.6 Две записи с одним prefab'ом дают две разные сущности с последовательными `index`
