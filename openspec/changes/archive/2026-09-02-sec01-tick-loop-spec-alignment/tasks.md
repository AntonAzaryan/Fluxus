## 1. Дельты требований (D1–D4)

- [x] 1.1 `specs/tick-loop/spec.md`: MODIFIED TICK-2 — фраза о моменте исполнения тика переписана на расписание, обе крайности (ждать сверх момента, исполнять досрочно) названы недопустимыми, ссылка на `netcode-transport` NTR-7 оставлена вместо повтора механики. Сценарий «Фрейм игрока не пришёл вовремя» переписан на дедлайн расписания. Блок MODIFIED несёт требование ЦЕЛИКОМ со всеми действующими сценариями: MODIFIED заменяет блок, и опущенный сценарий архивация молча выкинула бы.
- [x] 1.2 Там же: MODIFIED TICK-3 — исключений четыре; первые три остаются операциями ядра над своим жизненным циклом, четвёртое (применение авторитетного снапшота сетевой оболочкой, `client-shell` SHELL-8) названо чужим ядру и ограничено миром, который сам не идёт. Абзацем ниже — публикация операции применения снапшота и почему она не расширяет мутирующую поверхность (D4). Новый сценарий «Сетевой клиент применяет снапшот сервера».
- [x] 1.3 Перенести дельты в `openspec/specs/tick-loop/spec.md`. Изменение при этом НЕ архивируется: оно остаётся в очереди как запись о принятом решении. Проверка — `npx openspec validate --specs --strict` и `npm run spec-graph -- check`.
