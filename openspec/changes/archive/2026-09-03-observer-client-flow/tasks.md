## 1. Протокол: сентинель слота в приветствии

- [x] 1.1 `engine/net-ts/src/protocol/messages.ts`: именованная константа сентинеля «слота нет» (`NO_SLOT`, значение `-1`, шкала слотов — та же, что у `Pause.slot`), документация поля `WelcomeMessage.slot` (NTR-21, design D1/D2), разбор `Welcome` принимает слот в `[NO_SLOT, players.length - 1]`. Проверка — `protocol.test.ts`: сентинель разбирается, `-2` и прочие отрицательные отвергаются `ProtocolError`, обычный слот разбирается как прежде.

## 2. Сервер: приветствие наблюдателю

- [x] 2.1 `MatchServer.greet()`: допущенный наблюдатель получает `Welcome` с сентинелем, а в идущем матче — ещё и `Start` с исходным тиком начала (NTR-21, NTR-17); порядок — приветствие, `Start`, состояние паузы. Проверка — `observer.test.ts`: наблюдатель до старта получает `Welcome` и дожидается общего `Start`; вошедший после старта получает `Welcome` + `Start` + `Pause` одним `drain()`.
- [x] 2.2 Наблюдатель, пришедший в завершённый матч, получает `Reject` с исходом «матч завершён» (NTR-21). Проверка — тест в `observer.test.ts`.
- [x] 2.3 Молчание наблюдателя матча не завершает, а его уход не трогает слотов (NTR-21, NTR-6). Проверка — тест: матч с живым вводом обоих слотов и молчащим наблюдателем идёт дольше порога молчания; `Bye` наблюдателя не меняет ни `slotLease`, ни фазу матча.

## 3. Клиент: режим наблюдателя

- [x] 3.1 `MatchClient`: приветствие с сентинелем поднимает мир и переводит клиента в наблюдение — слота нет (`slot === undefined`), запас разметки не заводится, наблюдаемый признак `observer`; сверка приветствия с собственным `Hello` в обе стороны даёт `protocol-error` при расхождении (NTR-21, design D2). Проверка — тесты в `observer.test.ts` на оба расхождения и на успешный вход.
- [x] 3.2 `pushInput` наблюдателя не отправляет ничего и не наполняет кольцо своих кадров (NTR-21, design D4). Проверка — тест: после `pushInput` исходящих у клиента нет, `metrics.inputsSent === 0`, сервер соединение не рвёт.
- [x] 3.3 Сквозной прогон настоящих `MatchServer` + `MatchClient` на loopback: наблюдатель применяет снапшоты (прежний отказ «снапшот до Welcome» отсутствует), видит ОБЕ команды сцены с туманом, тогда как участник — только свою (NET-12, NTR-9), и принимает поток `Events` без фильтрации (NTR-15). Проверка — `observer.test.ts` целиком, сравнение состава `latest` наблюдателя и участника.
