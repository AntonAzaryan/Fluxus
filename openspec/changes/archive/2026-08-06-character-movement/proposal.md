# Proposal: character-movement

## Why

Движение сейчас — заглушка контента: JSON-система пишет `Velocity = Input.move × const` без разгона, снаряд интегрирует позицию сам мимо физики, коллизии бинарны («тег `blocksMovement` блокирует всех»), TimeScale на перемещение не действует. Для ощущаемого персонажа (разгон/торможение, уклон/перекат, прыжок через дыры и обрывы) и для настраиваемых коллизий (снаряды насквозь, условная блокировка, сущность-с-сущностью) нужны недостающие механизмы ядра и нормативная capability передвижения.

## What Changes

- Новая нативная TS-система `LocomotionSystem` (engine/core-ts): разгон/торможение к желаемой скорости из `Input`, машина состояний `Normal | Dodge | Roll | Airborne` (уклон → окно даблтапа → перекат; прыжок), все тюнимые числа — поля компонентов из контента, не константы ядра.
- Фильтрация коллизий по настройке: у коллайдера появляются `layer` / `blockMask` / `hitMask`; `blockMask` решает блокировку, `hitMask` даёт sensor-пересечение — событие без блокировки (снаряд, дамажащий насквозь).
- TimeScale действует на перемещение в точке интеграции: `PhysicsSystem` опт-ин в `getEffectiveDelta` (TIME-3/TIME-4); тайминги машины состояний идут по глобальным тикам.
- Направленный cliff-гейт: коллайдер обрыва несёт уровни обеих сторон; движущийся с полем `cliffRise` пересекает обрыв вверх, если перепад не больше `cliffRise`; спуск свободен. «Высота прыжка» выражается в уровнях террейна (PHYS-1: непрерывной высоты в симуляции нет).
- Прыжок перелетает дыры через существующий override уровня (ARENA-6) на время `Airborne`; перекат override не получает и проваливается штатно (ARENA-5). Новых механизмов арены не требуется.
- Летающие юниты выражаются готовыми деталями (постоянный `cliffRise` + постоянный override уровня) — без нового механизма.

## Capabilities

### New Capabilities

- `locomotion`: нативная система передвижения управляемой сущности — желаемая скорость из ввода, разгон/торможение, машина состояний уклона/переката/прыжка, конфигурация в компонентах.

### Modified Capabilities

- `physics`: PHYS-2 расширяется полями `layer`/`blockMask`/`hitMask` и sensor-семантикой; разрешение движения (PHYS-8) учитывает TimeScale через `getEffectiveDelta` и направленный cliff-гейт по `cliffRise`.
- `terrain`: TERR-5 — производные статические коллайдеры обрывов несут уровни обеих сторон ребра.

## Impact

- `engine/core-ts/src/systems/physics.ts` — маски, sensor-события, TimeScale в интеграции, cliff-гейт; `staticsFromTerrain` обогащается уровнями.
- `engine/core-ts/src/systems/locomotion.ts` — новая система; регистрация в `systems/registry.ts`, экспорт из `src/index.ts`.
- `engine/core-ts/src/systems/terrain.ts` — производная геометрия обрывов отдаёт уровни сторон.
- Контент: `content/scenes/duel.scene.json` — компоненты Locomotion/Collider обновляются, JSON-система `Movement` заменяется нативной, `FireballFlight` теряет самодельную интеграцию (снаряд идёт через физику с масками).
- Тесты: юниты core-ts (физика, локомоушен), интеграция в `engine/integration-ts`, golden-эталоны перегенерируются (`npm run golden`), JSON-схемы (`npm run schemas`).
