# Tasks: sec05-serialization-spec-alignment

Требования — `specs/serialization/spec.md` (**SER-1**, **SER-3**, **SER-4**, **SER-5**, **SER-7**) и `specs/snapshot-rewind/spec.md` (**SNAP-4**), разбор решений — design.md (D1–D7). Гейт локальный: `npm run check` из корня (CI нет).

Изменение заводится по факту сделанной работы: валидация спек против кода (`docs/reviews/spec-validation-2026-09-01/05-state-serialization.md`) назвала шесть расхождений; четыре чинятся текстом требования, два — кодом.

## 1. Дельты требований (D1, D3, D6, D7)

- [x] 1.1 `specs/serialization/spec.md`: MODIFIED SER-1 — обоснование порядка полей плоской формы переписано на «форма выходит документом (CLI-3), по нему сверяются реализации (CLI-6)»; добавлен абзац «хеш `worldInit` перестановку полей не ловит и обещать этого требование MUST NOT»; сценарий про хеш заменён двумя — «расходятся байты документа» и «хеш совпадает». Блок MODIFIED несёт требование ЦЕЛИКОМ со всеми действующими сценариями: MODIFIED заменяет блок, и опущенный сценарий архивация молча выкинула бы.
- [x] 1.2 Там же: MODIFIED SER-3 — JSON получает документы прогона и записи матчей (CLI-2, CLI-10), MessagePack сужен до кадра на проводе (NTR-13) и едущего в нём персонального снапшота (NET-18); добавлен абзац о границе процесса и сценарий «История снапшотов внутри процесса».
- [x] 1.3 Там же: MODIFIED SER-4 — область запрета сужена до данных движка и игры; конфигурация чужих инструментов разработки под требование не подпадает; добавлен сценарий «YAML-конфигурация чужого инструмента».
- [x] 1.4 Там же: MODIFIED SER-5 — симметричный критерий закрытого блока (поле документа, которого блок не называет, — тот же дефект) и граница «параметр вызывающей сборки полем документа MUST NOT быть»; добавлен сценарий «У блока опций появилась опция сборки».
- [x] 1.5 Там же: MODIFIED SER-7 — «все три поля» документа прогона → четыре, с `navigation` (`pathfinding` NAV-1); перечень объявлен обязанным оставаться полным.
- [x] 1.6 `specs/snapshot-rewind/spec.md`: MODIFIED SNAP-4 — «full copy → MessagePack» заменено на «full copy» плюс абзац «копия остаётся копией в памяти, сериализатор к ней не применяется»; добавлен сценарий «Снапшот кладётся в кольцо истории».
