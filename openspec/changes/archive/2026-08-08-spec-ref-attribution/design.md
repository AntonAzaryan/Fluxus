# spec-ref-attribution — design

## Context

Дефекты найдены машинно: `spec-graph check`, правило `attribution-mismatch` — заявленное в бэктиках имя capability сверяется с фактическим местом определения ID (карта строится из заголовков `### Requirement:`, а не из префикса — префикс дом не определяет). См. proposal.md «Why».

## Goals / Non-Goals

**Goals:** привести две заявленные атрибуции к факту; зелёный `spec-graph check`.

**Non-Goals:** любые другие правки этих требований; включение линта в гейт (отдельный коммит после архива, D7 архива `spec-graph-tool`); нормирование синтаксиса ссылок.

## Decisions

Правка минимальна — меняется только имя в бэктиках, по образцу уже принятых исправлений RNG-8/TERR-4 в `spec-modality-and-refs`. Дельты содержат полные секции требований (формат MODIFIED), различие с main — ровно одно слово в каждой.

## Risks / Trade-offs

- [Дельта устареет, если main-текст ARENA-5/LOC-1 изменится до архива] → change одной сессии: правка и архив идут подряд; сверку при синке делает сам `openspec archive`.
