# Proposal: vfx-record-field-description

## Why

Панель секций VFX (change `vfx-authoring-panel`) держала СВОЙ список полей записи эффекта — «подсказку», которой ED-14 разрешал отстать от формата. Отстать она успела сразу: `verticalOffset` в ней не было вовсе, составных полей (`radiusFromStat`, `colorAt`, `blink`) — тоже, а порядок последних двух полей разошёлся с форматом. Дописать окно доставленного стата автор из редактора не мог ни выбором, ни руками: составные значения панель показывала строкой JSON и правку запрещала. То есть за шаром заряда каста (REND-23) автор шёл в `manifest.json` текстовым редактором — ровно то, что ED-14 запрещает прямым текстом.

Разрешение «подсказке отстать» было компромиссом, а не решением: у формата ЕСТЬ владелец, и он вправе назвать состав своей записи машинно — так же, как код камеры называет набор типов эффектов (CAM-9). Тогда второго списка не остаётся, и отставать нечему.

## What Changes

- **Состав записи эффекта — машинное описание** (`EFFECT_FIELDS` модуля ассетов): имя поля, род значения (число / строка / составной объект), обязательность, границы числа и состав составного поля, в смысловом порядке. Им же закрывается состав записи при валидации и берутся границы общего прохода чисел — один перечень, а не два, совпавших по случайности.
- **Панель строит свои строки из описания**: список «дописать поле» — это его поля в его порядке, а род контрола строки (текст / число / подполя) — их род. Своего списка полей у редактора не остаётся ни в каком виде.
- **Составные поля правятся подполями** (ED-14): окно стата, порог цвета, мигание и вертикальное смещение раскрываются строками своих подполей; имеющееся поле пишется целиком каждой правкой, заводимое собирается черновиком (ED-23) и уходит одной операцией (ED-29), снятие — кнопкой той же строки. Находки владельца (`validateManifest`) стоят у своих строк, включая строки подполей (ED-8).

Спека: `editor` — MODIFIED ED-14 (состав полей приходит описанием формата; составные поля правятся подполями). `assets` не меняется: «состав записи закрыт валидацией» (ASSET-6, REND-23) — то же требование, у которого теперь есть машинная форма.

## Impact

- Спеки: `openspec/specs/editor/spec.md` (ED-14).
- Код: `engine/assets-ts/src/{visualSections,manifestFields,index}.ts`, `editor/ui-ts/src/areas/{assetVfx,assetVfxRows,assetVfxComposite}.ts`, `editor/ui-ts/src/i18n/locales/ui.{ru,en}.json`.
- Наблюдаемое: автор собирает окно стата, порог цвета и мигание из редактора; новое поле формата появляется в списке само. Валидация принимает и отвергает то же, что и прежде: тексты находок не менялись.
