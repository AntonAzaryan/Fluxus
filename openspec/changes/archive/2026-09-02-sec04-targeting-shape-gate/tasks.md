# Tasks: sec04-targeting-shape-gate

Требование — `specs/ability-system/spec.md` (**ABIL-5**), разбор решений — design.md (D1–D7). Гейт один и он
локальный: `npm run check` из корня репозитория (CI нет).

Изменение заводилось по факту сделанной работы: валидация спек против кода
(`docs/reviews/spec-validation-2026-09-01/04-gameplay.md`) нашла, что фигура шага не участвует ни в одной
проверке симуляции, а конус демо-сцены описан в документе дважды.
