# Tasks: extend-assets-native-formats

## 1. Контракт загрузчика и реестра (ASSET-3)

- [x] 1.1 Вид ассета — открытое множество строк с экспортируемыми известными константами вместо закрытого перечисления; рантайм-сверка вида загрузчика с видом запроса сохраняется
- [x] 1.2 Реестр ключуется парой «вид + расширение»: регистрация, поиск и замена; тест «одно расширение у двух видов не конфликтует»
- [x] 1.3 Контекст чтения для загрузчика: чтение файла по пути, относительному от ID ассета, с разрешением путей и без доступа к кэшу и реестру
- [x] 1.4 Недоступная зависимость переводит handle в `failed` с причиной, называющей недостающий файл; тест на загрузчике-заглушке из нескольких файлов

## 2. Нормализованная модель (ASSET-5)

- [x] 2.1 Зафиксировать в контракте каноническую ориентацию (Z-up, правая тройка) и единицу измерения; описать обязанность загрузчика приводить к ним
- [x] 2.2 Узел скелета: позиция, поворот и масштаб покоя плюс необязательная матрица обратной привязки (отсутствие = выводится из позы покоя)
- [x] 2.3 Описание материала: базовый цвет-фактор и карта, металличность, шероховатость, карта нормалей, эмиссия, режим прозрачности; карты ссылаются на слот текстуры, а не на путь
- [x] 2.4 Режим интерполяции (ступенчатый/линейный/кубический) на канал анимационного трека
- [x] 2.5 Текстурный ассет — декодированное изображение: размеры, формат пикселей, пиксели

## 3. Загрузчики под расширенный контракт

- [x] 3.1 MDX: поворот и масштаб покоя нейтральные, обратная привязка не заполняется; поведение выхода не меняется
- [x] 3.2 MDX: материал из слоя геосета — значения, которые сегодня захардкожены в рендере, переезжают в данные ассета
- [x] 3.3 MDX: режим интерполяции канала — ступенчатый там, где формат просит «без интерполяции», линейный в остальных случаях (эрмит и безье не переводятся, см. design решение 6)
- [x] 3.4 Декодер PNG: распаковка через `DecompressionStream` (зависимость на inflate не понадобилась — см. правку решения 7), снятие построчных фильтров, 8-битные цветовые типы включая палитру и альфу, приведение 16 бит к 8, внятная ошибка на чересстрочные
- [x] 3.5 PNG-загрузчик отдаёт декодированное изображение; тесты декодера на эталонных PNG всех поддержанных цветовых типов, в Node без браузера

## 4. Потребитель (render-ts)

- [x] 4.1 Построение скелета из полной позы покоя; явные матрицы обратной привязки, когда загрузчик их дал
- [x] 4.2 Материал инстанса из описания ассета вместо захардкоженной серой заглушки; пер-инстансность материалов и правила скинов (REND-3, REND-6) сохраняются

- [x] 4.4 Режим интерполяции доезжает до анимационных треков рендера
- [x] 4.5 Тесты пути скинов в headless-среде — теперь он исполним и должен быть покрыт

## 5. Когерентность

- [x] 5.1 `assets-ts` по-прежнему не зависит от рендер-библиотеки, DOM и GPU-API (проверка зависимостей пакета и импортов)
- [x] 5.2 Тесты и типы зелёные в обоих пакетах; ядро симуляции без диффа, golden-файлы проходят
- [x] 5.3 Проверка на демо-сцене: террейн, модель, анимации idle/каста, смена скина steel↔ember и спавн фаербола работают, консоль чистая. НЕ проверено на глаз: вертикальная ориентация текстуры (демо-скины почти симметричны, различить переворот на них нельзя) — см. комментарий в `skins.ts`, где выбор `flipY = false` обоснован совпадением UV-конвенций MDX и glTF
- [x] 5.4 `openspec validate extend-assets-native-formats --strict` проходит; после реализации — синхронизация дельты в `openspec/specs/assets/spec.md`
