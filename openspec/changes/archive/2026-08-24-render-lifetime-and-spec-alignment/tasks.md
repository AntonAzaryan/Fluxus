## 5. Тесты

- [x] 5.1 `PresentationStage.dispose()` зовёт `dispose` подсистем в порядке, обратном регистрации, и подсистема без метода снос переживает (REND-31)

- [x] 5.3 `FogSubsystem.dispose()` освобождает маску, цель отрисовки и пост-материал — спаями `.dispose` объектов THREE (FOW-7, REND-31)
- [x] 5.4 `TerrainSubsystem.dispose()` освобождает геометрии чанков и материалы, сцена остаётся без его мешей (REND-31)
- [x] 5.5 `OverlaySubsystem.dispose()` освобождает разделяемые геометрии и материалы, группа снята со сцены (REND-31)
- [x] 5.6 `ModelsSubsystem.dispose()` освобождает батчи, разделяемые геометрии модели и VAT-текстуру; порядок таков, что геометрия ассета освобождается ПОСЛЕ снятия чужих атрибутов батчем (design Решение 6)
- [x] 5.7 Цикл переподач манифеста, меняющих набор рисуемых частей записи, не растит число батчей монотонно, и освобождённые батчи отданы (`ModelBatch.dispose`) — REND-31, REND-17
- [x] 5.8 Переподача, не меняющая записи, батчей не трогает; правка одной записи не трогает батч соседней на той же модели. Страховка `count === 0` тестом НЕ покрывается: конструктивного пути в неё нет — непустой батч всегда имеет достижимый ключ (design Решение 5)
- [x] 5.9 Опустевший батч БЕЗ переподачи остаётся в кэше — игровой путь не изменился (REND-20, REND-31)
- [x] 5.10 `EffectsSubsystem.dispose()` и `ParticlesSubsystem.dispose()` освобождают своё и снимают группы со сцены (REND-23, REND-24)
- [x] 5.11 `batchLevels` относит к своему ровно геометрии цепочки, а снос батча отдаёт их после обёрток и не трогает буферы ассета (REND-22 → REND-31)
- [x] 5.12 Снос подсистемы частиц отдаёт ресурсы документа эффекта по одному разу — на документе с двумя системами на общем материале и общей геометрии; повторный снос не отдаёт ничего заново (REND-24 → REND-31)
