# determinism-core — дельта sec12-cross-consistency-spec-alignment

## MODIFIED Requirements

### Requirement: DI-4 Navigation API опционален на уровне ядра

Navigation API (`pathfinding` NAV-1) SHALL быть опциональным на уровне ядра/DI: ядро способно собираться и тикать без него. В отличие от Physics API, для данной игры он тоже необязателен, и держится это НЕ на отсутствии агентов, которым нужен поиск пути: платформа поведения NPC существует (`npc-behavior` NPC-1), четыре её системы стоят в нормативной таблице порядка DET-9, а конфиг сцены объявляет раздел `npc` (`serialization` SER-7). Держится оно на том, что политика движения написана НАД навигационным швом и обязана работать по обе его стороны: сцена без Navigation API тикает с NPC штатно — маршрут волны идёт waypoint'ами и прямым seek, — и тем же прямым seek движение деградирует, когда поиск вернул недостижимость или исчерпал бюджет (`npc-behavior` NPC-6). Управление игроками поиска пути не требует вовсе: оно прямое.

Отсутствие навигации SHALL быть штатным режимом сборки, а не деградацией: сцена без неё тикает полностью, и системы, которым она не нужна, о ней не знают. Система, которой Navigation API необходим, при его отсутствии SHALL падать с ошибкой на общих основаниях опциональной зависимости (`data-driven-systems` SYS-5).

#### Scenario: Тик без навигации

- **WHEN** ядро собрано без Navigation API и в мире нет систем, требующих поиск пути
- **THEN** `tick()` отрабатывает штатно

#### Scenario: Сцена с крипами без навигации

- **WHEN** ядро собрано без Navigation API, а сцена объявляет волны крипов
- **THEN** `tick()` отрабатывает штатно: по `npc-behavior` NPC-6 движение идёт waypoint-маршрутом и прямым seek, и наличие NPC обязательности навигации не создаёт

#### Scenario: Система, объявившая навигацию обязательной

- **WHEN** в сцену добавляется система, которой Navigation API необходим, а сборка его не содержит
- **THEN** система падает с ошибкой, называющей зависимость (`data-driven-systems` SYS-5)
