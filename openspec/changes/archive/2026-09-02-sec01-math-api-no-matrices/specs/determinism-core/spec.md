# determinism-core — дельта

## MODIFIED Requirements

### Requirement: DI-2 Math API обязателен

Math API SHALL быть обязательной зависимостью ядра. Его состав — операции над fixed-point скалярами формата `fixed-point-math` FP-1 и над двумерными векторами; матриц в нём MUST NOT быть, и заделом на них требование считать MUST NOT. Основание: симуляционная геометрия двумерна и состоит из примитивов (DET-8), а матричные преобразования принадлежат представлению (`rendering`), которое зависимостью ядра не является вовсе. Вторая реализация ядра (CORE-2), прочитавшая это требование, матричного модуля поэтому не пишет: в эталонных прогонах (`cli-testing` CLI-5) ей не встретится ни одного его употребления.

#### Scenario: Сборка ядра без Math API

- **WHEN** ядро собирается без предоставленного Math API
- **THEN** сборка невозможна — зависимость обязательная

#### Scenario: Реализации понадобилась матрица

- **WHEN** во второй реализации ядра или в новой нативной системе возникает нужда в матричном преобразовании
- **THEN** это признак, что в симуляцию поехала геометрия представления (DET-8): матриц Math API не содержит, и появление их — отдельное решение с собственным основанием, а не деталь сборки
