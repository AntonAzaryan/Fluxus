## MODIFIED Requirements

### Requirement: CORE-1 Ядро только на TypeScript

Реализация ядра SHALL быть только на TypeScript. Вторая реализация ядра (CORE-2) SHALL быть отдельным осознанным решением, а не работой, идущей параллельно первой: её назначение — оптимизация серверной стороны, и до такого решения реализация в дереве одна.

#### Scenario: Выбор языка для новой системы ядра

- **WHEN** добавляется системный код ядра
- **THEN** он пишется на TypeScript, и вторая реализация от этого не начинается: её старт — отдельное решение, а не следствие роста первой

### Requirement: CORE-4 Никаких WASM-мостов, пока реализация ядра одна

Пока реализация ядра одна (CORE-1), WASM-мосты между реализациями MUST NOT использоваться. Запрет SHALL пересматриваться с появлением Rust-реализации (CORE-2): её исполнение на клиенте через WASM становится предметом замера скорости, а не самоочевидным решением.

#### Scenario: Предложение переиспользовать Rust-ядро в браузере через WASM

- **WHEN** возникает такая опция, пока реализация ядра одна
- **THEN** она отклоняется; клиент исполняет TS-ядро напрямую

### Requirement: DI-4 Navigation API опционален на уровне ядра

Navigation API (`pathfinding` NAV-1) SHALL быть опциональным на уровне ядра/DI: ядро способно собираться и тикать без него. В отличие от Physics API, для данной игры он тоже необязателен — управление игроками прямое, а крипов и NPC, которым нужен поиск пути, в игре нет.

Отсутствие навигации SHALL быть штатным режимом сборки, а не деградацией: сцена без неё тикает полностью, и системы, которым она не нужна, о ней не знают. Система, которой Navigation API необходим, при его отсутствии SHALL падать с ошибкой на общих основаниях опциональной зависимости (`data-driven-systems` SYS-5).

#### Scenario: Тик без навигации

- **WHEN** ядро собрано без Navigation API и в мире нет систем, требующих поиск пути
- **THEN** `tick()` отрабатывает штатно

#### Scenario: Сцена с крипами

- **WHEN** в сцену добавляются агенты, которым нужен поиск пути
- **THEN** Navigation API обязан быть предоставлен сборке, иначе их система падает с ошибкой, называющей зависимость
