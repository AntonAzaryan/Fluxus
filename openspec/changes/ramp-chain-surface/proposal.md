## Why

Правило углов визуальной поверхности (`rendering` REND-9, `cornerLevels`) задумано для одиночной рампы между двумя плато: клетка-рампа поднимает/опускает рёбра к уровням соседей. Для ЦЕПОЧКИ рамп — длинного склона в несколько уровней, каким его естественно даёт скалпт-источник (`blender-pipeline` BLND-13) и каким его можно нарисовать кистями, — ступенчатая форма получается разрывной: клетка-рампа с соседями ±1 с двух сторон охватывает углами два уровня, соседние рампы расходятся в общих узлах на целый уровень, и в кадре посреди гладкого склона появляются вертикальные разрывы без cliff-геометрии. Остаток кривизны импорта восстанавливает только верхнюю сторону узла (BLND-13 называет предел явно).

## What Changes

- Непрерывность узловой высоты ступенчатой формы на цепочках рамп: правило углов (или его обобщение) даёт в общем узле соседних рамп одно значение.
- Импорт скалпта после этого автоматически восстанавливает длинные склоны точно — правка самого конвейера не требуется (остаток уже считается через правило рендера).
