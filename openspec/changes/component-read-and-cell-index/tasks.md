## 1. ECS-7 в ядре

- [ ] 1.1 `engine/core-ts/src/ecs/world.ts`: `getField` сверяется с маской владения и живостью до чтения ячейки — при отсутствии владения или живости возвращает нейтральное значение типа поля (`0` для `i32`/`fixed`, «ссылки нет» для `entity`); проверки имён компонента и поля остаются броском и порядок их не меняется
- [ ] 1.2 Там же: мягкий assert (`fixed-point-math` FP-4) на чтении без владения — через существующий `assert` из `src/debug.ts`, без влияния на возвращаемое значение и без аллокаций на пути тика
- [ ] 1.3 Проверить, что все чтения идут через одну точку: `SystemContext.get` (`sim/tick.ts`), нативные системы (`systems/terrain.ts`, `physics.ts`, `arena.ts`, `visibility.ts`, `time.ts`), `sim/filter.ts`, `sim/rewind.ts`. Второго пути чтения ячейки в обход маски остаться не должно — иначе ECS-7 выполняется не везде
- [ ] 1.4 Убедиться, что `commands.peekField` (CMD-5) не становится обходным путём: точечное чтение накопленной команды отвечает о буфере, а падение в мир при её отсутствии обязано идти через тот же `getField`
