# TOFU-доверие удалённого хоста в десктоп-контейнере

## Why

Менеджер в контейнере умеет подключаться только к локальному агенту (DSK-8 — закрепление объявленного сервиса); удалённый хост (VPS с host bundle, SRV-7) из контейнера недостижим: его self-signed сертификат ничем не закреплён, Chromium его режет, а страница принять не может по устройству среды (`browserSocket`). Это было названо Non-Goal change'а `service-cert-pinning`; production-путь хостинга без него не замыкается — управлять VPS из менеджера нельзя.

## What Changes

- **Второе основание доверия в контейнере** (расширение DSK-8): сертификат, не совпавший с закреплением объявленного сервиса, контейнер предъявляет ЧЕЛОВЕКУ — системный диалог с origin соединения и отпечатком SHA-256. Явное согласие — сертификат принят и закреплён; отказ или закрытие диалога — соединение отвергнуто. То же trust-on-first-use, что у клиентской библиотеки (SRV-3), но на TLS-слое.
- **Книга доверия контейнера**: принятые решения переживают сессию — «origin → отпечаток» в каталоге данных контейнера; повторное подключение к известному origin с тем же отпечатком проходит молча. Изменившийся отпечаток известного origin — громкий случай: диалог с предупреждением о смене и обоими отпечатками, продолжить можно только новым явным решением (та же семантика, что SRV-3).
- **Решение о доверии — вопрос среды, логика — хост-слоя**: сверка, книга и порядок решения живут в `src/host/` (чистый Node, в гейте); клей Electron даёт только диалог. Наплыв повторных попыток одного origin схлопывается в один диалог.
- **Страница менеджера не меняется**: пиннинг рукопожатия `controlClient` остаётся второй линией; текст причины отказа в `browserSocket` уточняется — в контейнере путь теперь есть.

## Capabilities

### New Capabilities

_нет_

### Modified Capabilities

- `desktop-shell`: DSK-8 — второе основание доверия (явное решение человека), книга доверия через границу сессий, громкая смена отпечатка, схлопывание диалогов.
- `server-manager`: MGR-5 — удалённый хост из контейнера достижим через решение человека (DSK-8); граница остаётся только у обычной вкладки браузера.

## Impact

- `desktop/shell-ts`: `src/host/` — книга доверия (файл в каталоге данных, атомарная запись) и порядок решения с внешним «спросить человека»; `src/electron/main.ts` — диалог `dialog.showMessageBox` в обработчике `certificate-error`; контрактный сьют Electron — случаи «согласие открывает канал», «отказ отвергает», «смена отпечатка — предупреждение».
- `game/server-agent-ts`: только текст `PAGE_LIMIT` в `browserSocket` (причина отказа называет контейнерный путь точнее).
- `game/server-manager-ts`: без изменений кода.
- Симуляция, golden-эталоны, протоколы — не затрагиваются.
