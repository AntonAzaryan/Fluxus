## 2. Хостинг

- [ ] 2.1 `BotHost` (D3): `Transport` + фабрика мозга + профиль → `MatchClient` + `ClientHost`, склейка `ClientStep`→`observe` и `InputSource`→`sample`; несколько ботов в одном хосте (BOT-4)
- [ ] 2.2 Тонкие worker-entry: браузерный Worker и node `worker_threads`, оба через `PortTransport`; хелпер сборки «создать пару портов, раздать серверу и боту»
- [ ] 2.3 Скриптовый мозг для тестов (D6): детерминированный, без wall-clock и случайности
- [ ] 2.4 Интеграционный тест: loopback-матч сервер+бот через внутрипроцессный транспорт — бот подключается, шлёт ввод, сервер кода «для бота» не исполняет (BOT-1); медленный мозг не сбивает каденс отправки (BOT-2)
- [ ] 2.5 Тест границы честности (BOT-3): in-process сборка listen — мозг конструируется без ссылки на мир сервера, наблюдения содержат только фильтрованный поток своего слота
