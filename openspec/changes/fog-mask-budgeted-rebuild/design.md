## Context

Мотивация — proposal.md «Why»; требования — делты FOW-11 и REND-30. Текущее устройство:

- Вся перестройка маски выполняется синхронно в `FogSubsystem.syncTick` (таск обработчика сообщения канала, между rAF): скан сущностей → сигнатура входов → при несовпадении `clear` → `reveal`×наблюдатели → `smooth` (два полных прохода) → взвод `settling`. Растр один (`mask.data` — цель, `shown` — показываемое); текстура обёрнута вокруг `shown`.
- `updateFrame` при `settling` каждый кадр гонит полный проход схождения `shown → mask.data`, полную загрузку текстуры и полный блит миникарты. На дуэли (маска 384×384, обзор 24) окно после смены уровня ~24 кадра по ~1,5–2,5 мс.
- Hybrid-тени: `staticStale` — один глобальный флаг; кадр статической перерисовки безусловно вытесняет динамическую карту. Замена чанк-меша террейна (мутация пола TERR-6) дёргает `dropCaster`+`setCaster` → `staticStale` каждый кадр → динамическая карта не обновляется ни разу (perf-секции match-эталонов: `lightingDynamicCasters = 0`).
- Новый корень в `setCaster` взводит `flagsStale` → обход всего реестра кастеров в следующем кадре; точечный путь `applyFlagsTo` покрывает только повторную регистрацию того же корня.

## Goals / Non-Goals

**Goals:**

- Убрать ~3 мс синхронной перестройки из таска доставки: порции под тексельный бюджет в кадровой фазе, атомарный commit.
- Ограничить окно рассеивания грязными блоками: работа кадра пропорциональна неустоявшейся области.
- Чередование фаз hybrid-теней; точечные флаги для новых динамических корней.

**Non-Goals:**

- Частичная загрузка текстуры маски (`copyTextureToTexture`) — фаза 2, только если bench покажет, что загрузка целиком заметна (требует расширения `FogRendererLike` и всех тестовых дублей).
- Коалесинг доставок на main в `RemoteHost` (кандидат следующей итерации — трогает контракт SHELL-3/4).
- Демонтаж/пул detailed-инстансов, кэш клонов материалов fade, гейт анимаций по видимости — следующая итерация.
- Дублирование ярусов кастеров (demote чанка в dynamic при мутации) — отвергнуто в этой итерации: меняет тон тени на горячем чанке (доля интенсивности hybrid) и букву REND-30 о ярусе террейна.
- Данные (`fog.maskResolution: 6` в balanced, `dissolveSeconds: 0.25`) — решение геймдизайна, вне чейнджа.

## Decisions

**D1. Ось нарезки — строки внутри существующих проходов.** Фазовая машина `IDLE → CLEAR → REVEAL(наблюдатель, строки) → SMOOTH_H → SMOOTH_V → COMMIT`. Полярный depth-буфер наблюдателя строится целиком при входе в его REVEAL (~тысячи операций, нарезать нечего); тексельный цикл нарезается по `ty`. Бюджет — тексели на кадр (PERF-3, машинно-независимость), по умолчанию таким, чтобы полная перестройка дуэли укладывалась в ≤3 кадра (~200k тексель-операций/кадр). Альтернатива «наблюдатель как порция» отвергнута: один наблюдатель — ~85 % растра, спайк не делится.

**D2. Двойной буфер с атомарным commit.** Порции пишут задний буфер; `commit()` меняет ссылки местами. Читатели (`shown`-цель рассеивания, миникарта, `valueAt`, debug-источник) всегда видят целиком построенный передний растр — инвариант FOW-11. Синхронный путь (`clear→reveal→smooth` на переднем) сохраняется для `snapAll` и тестов.

**D3. Три сигнатуры: `signature` (закоммичено) / `building` (в полёте, она же стабильный снимок входов для порций) / `pending` (последняя отложенная доставка).** Конфляция: новая доставка перезаписывает `pending`; перестройка в полёте никогда не перезапускается — достроить, закоммитить, взять `pending`. Гарантия продвижения: при доставках каждые 2 кадра и перестройке за 3 кадра рестарты голодили бы маску вечно. Черствость ≤ длительности одной перестройки (~50 мс) — консервативна (FOW-9) и на порядок меньше авторского рассеивания.

**D4. Перестройка живёт в `updateFrame` даже при бесконечном бюджете** (commit в первый же кадр). У счётчика ровно одна стадия — двойной атрибуции syncTick/frame не бывает; все растровые счётчики тумана переезжают в `frame`, `fogEntitiesScanned` остаётся в `syncTick` (скан по-прежнему за доставку). Честная атрибуция PERF-2 важнее привычной секции; эталоны регенерируются `golden:cost`.

**D5. Грязное окно рассеивания — блоки 16×16.** Набор грязных блоков вычисляется на commit поблочным сравнением старого и нового переднего растра (оба существуют в момент свопа); блоки, не устоявшиеся с прошлого окна, остаются в наборе (прерванное рассеивание). Проход рассеивания и блит миникарты идут только по флагнутым блокам; устоявшийся блок снимает флаг; `settling = (набор непуст)`. `putImageData` — с грязным прямоугольником (расширить структурный тип `FogLayerContext`, учесть Y-флип). Альтернатива — AABB объединения кругов — отвергнута: на дуэли круг ~85 % растра, экономии нет.

**D6. Тени: статическая перерисовка не два кадра подряд.** Ворота в планировщике: кадр статической перерисовки допустим, только если предыдущая фаза не `static` или динамических корней нет. Под непрерывной инвалидацией фазы чередуются, каждая карта отстаёт максимум на кадр — та же величина черствости, которую design hybrid уже принял для динамической карты. Альтернатива (demote чанка) — в Non-Goals.

**D7. Точечные флаги для нового корня.** `setCaster` нового корня применяет флаги адресно (`applyFlagsTo`) вместо взвода `flagsStale`, если фаза кадра известна; полная инвалидация остаётся для смены фазы и статических путей.

## Risks / Trade-offs

- [Полурастр утёк читателю через сохранённую ссылку на `mask.data`] → своп меняет ссылки; аудит всех мест, где ссылка на растр кэшируется (текстура, debug-источник, миникарта), с тестом атомарности.
- [Livelock перестройки при непрерывном движении] → запрет рестарта в полёте (D3) + тест коалесинга.
- [Сломанные ожидания тестов D4-сигнатуры (`syncTick` → мгновенный `rebuilds`)] → прокачка `updateFrame` в тестах; `rebuilds` определяется как закоммиченные перестройки.
- [`steadyFrame`: кадр commit отличается от кадров рассеивания] → тест побитовой стабильности сверяет устоявшиеся кадры, кадр commit исключён явно.
- [Черствость маски видна на кромке при резком развороте] → консервативное направление (туман дольше), бюджет ≤3 кадров, поверх — авторское рассеивание 0,4 с; проверка глазами через `bench:demo --drive cliff-jump`.
- [Чередование фаз задерживает статическую тень при непрерывном перетаскивании в редакторе] → отставание ≤1 пропущенного кадра, зафиксировано сценарием REND-30; одиночная правка по-прежнему «не позже следующего кадра».
- [Регрессия cost-эталонов по невнимательности] → перенос стадий счётчиков — отдельная задача с явной регенерацией и диффом в коммите.

## Migration Plan

Чистая правка render-ts + тесты + регенерация cost-эталонов одним PR; sim-голдены не двигаются. Откат — revert коммита (эталоны в том же коммите).
