# Справочник DSL: операторы и действия

Источник истины — `engine/core-ts/src/dsl/expr.ts` (таблица `OPS`) и `actions.ts` (таблица `ACTIONS`); при расхождении прав код. Таблицы закрыты: незнакомое имя отвергает регистрация системы (SYS-3).

## Операторы выражений (expr.ts)

Все числа — сырой Q16.16, кроме явно отмеченных `i32`. Каждый оператор — объект с одним ключом и массивом аргументов.

### Окружение

| Оператор | Сигнатура | Примечание |
|---|---|---|
| `var` | `["имя"]` | биндинг из `as`/`let`/`random`; неизвестное имя — ошибка |
| `tick` | `[]` | номер тика, **сырое целое** — для арифметики нужен `fromInt` |
| `getComponent` | `[entity, "Comp", "field"]` | масштаб поля тот, что в схеме (`fixed`/`i32`); читает мир, а не отложенные команды (QUERY-3) |
| `hasComponent` | `[entity, "Comp"]` | → bool |
| `isAlive` | `[entity]` | → bool |
| `eventField` | `[eventRef, "field"]` | `eventRef` — имя из `forEachEvent`; отсутствующее поле — ошибка, не 0 |

### Мир: террейн и физика

| Оператор | Сигнатура | Примечание |
|---|---|---|
| `hasFloorAt` | `[vec]` | есть ли пол под мировой позицией (TERR-8); за краем сетки тотален; сцена без террейна — ошибка вычисления |
| `raycastHit` | `[from, to, ignore, "tag"?]` | → bool: есть ли попадание на отрезке (EXPR-8); различает статику и пустоту |
| `raycastEntity` | `[from, to, ignore, "tag"?]` | сущность ближайшего попадания (PHYS-7); статика и «ничего» — оба `-1` |
| `raycastPoint` | `[from, to, ignore, "tag"?]` | точка ближайшего попадания; без попадания — `to` |

`ignore` — сущность-источник, исключаемая из обхода (тотален: `-1` не исключает никого); `"tag"` — необязательное **литеральное** имя тега коллайдеров. Сцена без Physics API — ошибка вычисления. По лучу на оператор, кэша нет.

### Арифметика Q16.16

`+`, `-`, `*`, `/` (по два аргумента), `min`, `max`, `abs`, `sqrt`, `clamp [x, lo, hi]` (порядок сведения нормативен: `min(max(x, lo), hi)`).

`sin`, `cos` — угол в Q16.16-**долях оборота**: `16384` = 90°, `65536` = полный оборот (FP-7), не радианы.

Приведение масштаба: `fromInt` (целое → Q16.16), `toInt` (Q16.16 → целое, усечение).

### Маски `i32`

`bitTest [mask, bit]` — проверка бита 0..31 → bool (литеральный номер проверяет регистрация, вычисляемый — тик); фронт кнопки ввода (TICK-4). `maskCovered [mask, cover]` — истина, когда каждый взведённый бит `mask` взведён и в `cover`; пустая маска покрыта любой (стелс против детекции, FOW-3). Других битовых операций нет: маски в арифметику не выпускаются.

### Сравнения и логика

`<`, `<=`, `>`, `>=`, `==`, `!=` (операнды одного типа; векторы целиком сравнивать нельзя — только покомпонентно); `and`, `or` (≥2 аргументов, вычисляются все — короткого замыкания с эффектами тут нет, выражения чистые), `!`; `if` — `[cond, then, cond2, then2, …, else]` (нечётное число аргументов).

### Векторы

`vec [x, y]` — конструктор; `vec.add`, `vec.sub`, `vec.dot`, `vec.length`, `vec.lengthSq`, `vec.normalize`, `vec.scale [v, k]`, `vec.x`, `vec.y`. Вектор — значение `{x, y}` в Q16.16; в поля компонентов кладётся покомпонентно.

## Действия (actions.ts)

Объект с одним ключом-действием и **именованными** аргументами. Обязательные аргументы проверяет регистрация (SYS-3); необязательные (`radius`, `else`, `subStream`, `nearestTo`, `limit`, `overrides`, `data`) читаются напрямую и отсутствие переживают.

### Мутации ECS (все — через Command Buffer, видимы после flush системы)

| Действие | Аргументы |
|---|---|
| `modifyComponent` | `entity`, `component`, `values: {поле: expr}` |
| `addComponent` | `entity`, `component`, `values` |
| `removeComponent` | `entity`, `component` |
| `spawnEntity` | `prefab`, `overrides?: {Comp: {поле: expr}}` |
| `destroyEntity` | `entity` |
| `emitEvent` | `type`, `data?: {поле: expr}` — масштаб полей определяет эмитент |

### Специализированные

| Действие | Аргументы | Примечание |
|---|---|---|
| `addTween` | `entity`, `def`, `from`, `to`, `duration`, `easing?`, `ignoreTimeScale?` | `def`/`easing`/`ignoreTimeScale` — сырые `i32`; `def` — индекс в `scene.tweens` |
| `addModifier` | `component`, `entity`, `id`, `value` | `id` — сырое целое, `value` — множитель Q16.16 |
| `removeModifier` | `component`, `entity`, `id` | отсутствующий id — не ошибка |
| `carveFloor` | `at`, `radius?` | снять пол арены вокруг мировой позиции (TERR-8); `radius` — расстояние в Q16.16, не число клеток; без `radius` — одна клетка под точкой (отличимо от нуля) |

### Управление потоком и биндинги

| Действие | Аргументы | Примечание |
|---|---|---|
| `if` | `cond`, `then: [...]`, `else?: [...]` | cond обязан быть булевым |
| `let` | `bindings: {имя: expr}`, `do: [...]` | биндинги вычисляются во внешней области, не по цепочке; каждый — **изменяемая ячейка** (ACT-4) |
| `set` | `name`, `value` | присваивание биндингу ближайшего объемлющего `let`; имя из `as`/`random` — ошибка регистрации. Так пишутся свёртки: аккумулятор в `let`, `set` в теле `forEach` (пример — `engine/tests/golden/dsl-fold.scenario.json`) |
| `forEach` | `query`, `as`, `do`, `nearestTo?`, `limit?` | query: `all`/`any`/`not` (списки компонентов), `withTag`, `withinRadius: {center, radius}` (center/radius — выражения); результат материализован до итерации. `nearestTo` — вектор, обход по возрастанию квадрата расстояния; `limit` — Q16.16, приводится `toInt`, отрицательный — ошибка вычисления (ACT-5) |
| `forEachEvent` | `type`, `as`, `do` | `as` связывает ссылку на событие для `eventField`; длина шины берётся до обхода |
| `random` | `as`, `do`, `subStream?` | Q16.16 из стрима системы (или именованного суб-стрима) |
| `randomBelow` | `bound`, `as`, `do`, `subStream?` | равномерное целое `[0, bound)`, bound ≥ 1 (в Q16.16, приводится `toInt` внутри) |
