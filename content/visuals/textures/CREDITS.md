# Происхождение текстур

- `water-normal.png`, `water-foam.png` — сгенерированные тайлящиеся карта
  нормалей спокойной воды (512×512, RGB) и шум пены/каустики (512×512, RGB:
  R — сеть каустики, G — пятна рваной кромки пены, B — пузырьки). Обе целиком
  выведены из формул `scripts/gen-water-textures.mjs` (`npm run
  textures:water`): поле высот — сумма направленных волн с целым волновым
  вектором и октав периодического value-шума, нормаль — из градиента с
  нормировкой максимального наклона; каустика — сеть Ворли в два масштаба на
  искривлённой шумом области, пена — октавы value-шума под порогом контраста,
  пузырьки — мелкий Ворли по расстоянию до центра. Генератор детерминирован (xorshift32 с
  фиксированным зерном), поэтому файл пересоздаётся, а не подбирается заново,
  и лицензировать здесь нечего. Прежние карты из
  [tuxalin/water-shader](https://github.com/tuxalin/water-shader) (MIT) сняты:
  их частотный состав — штормовая крошка, которая под изометрической камерой
  сворачивалась в шум. Используются секцией `water` парного
  presentation-документа дуэльной арены как деталь источника `textured`
  (REND-35).
- `ground-grass.png`, `ground-dirt.png`, `ground-rock.png`, `ground-cliff.png` —
  сгенерированные тайлящиеся покрытия террейна (512×512, RGB): трава,
  утоптанная земля и камень для площадок пола плюс земля со слоями породы и
  камнем для стенок обрывов и юбки. Целиком выведены из формул
  `scripts/gen-ground-textures.mjs` (`npm run textures:ground`): трава — пятна
  тона октавами периодического value-шума, пятна сухой земли под порогом,
  мазки-травинки на тороидальном холсте, редкие цветки и крапины; породные
  поверхности — одно ядро с разными палитрами: пятна тона, горизонтальные
  прослойки синусоидой (у площадок выключены), камни ячейками Ворли с тёмным
  швом и крапины. Генератор детерминирован (xorshift32 с фиксированным зерном),
  лицензировать нечего. Это ЗАГЛУШКИ АРТА демо: слоты называет tileset в
  разделе `terrain` манифеста визуалов (ASSET-15), раскраску клеток — карта
  `visuals/duel.paint.json`, и заменить любую картинку настоящей — правка
  контента, а не кода (REND-39).
- `fire-soft.png` — сгенерированная мягкая круглая маска частицы 64×64
  (grayscale+alpha, PNG): яркость всюду 255, альфа — радиальный спад
  `t = clamp(1 − r, 0, 1)`, `a = t²(3 − 2t)`, где `r` — расстояние от центра в
  долях половины стороны. Своего изображения у неё нет — она РЕЖЕТ квад
  эмиттера в мягкий круг, — поэтому лицензировать здесь нечего, а формула
  записана затем, чтобы файл можно было пересоздать, а не подобрать заново.
  Употребляется картой материала эмиттерного ассета горящей полосы
  (`visuals/effects/boss-fire.effect.json`, ASSET-14): без неё частица
  рисуется голым непрозрачным квадратом.
