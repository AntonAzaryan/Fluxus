## Сделано (в ветке, все пакетные тесты и спеки зелёные на момент слияния)

Новое (§4): курсор на поверхности и мировые якоря HUD (REND-41/42, HUD-10), слои миникарты, камера наблюдателя и путь (CAM-10, ASSET-17), фото-режим, текстурирование террейна (ASSET-15, REND-39, BLND-14, аддон Blender), наземные телеграфы, лучи и ленты (REND-43), композит теней вместо `staticShare` и апсемпл bloom (REND-30/34), распил `models.ts` на 13 модулей с носителями ярусов, отсечение с учётом теневой пирамиды и позы узлов обоих ярусов (REND-20/21/24), поколение ассетов входом (REND-1/31), канал тинта и растворение трупов (REND-40, ASSET-18, REND-4), задержка под джиттер и dirty-извлечение (REND-2, SHELL-3/4, кодек v7), глобальная шкала времени презентации (REND-25/38), бюджет кадра (REND-44), проходы пост-обработки списком и FXAA, ручка хоста `frame.renderScale` (QUAL-5), окружение как данные секции `lighting` (REND-29), LOD и авторинг VFX в редакторе (ED-14/15). Этапы roadmap 53–65 в `docs/architecture.md`.

## Осталось добить

1. **Ветка `wt/models` (запушена): фаза «волна спавна под бюджетом»** — коммит `wip(render): волна спавна под бюджетом кадра`. Чейндж `models-spawn-budget` заархивирован, `spawnQueue.ts` и `spawnBudget.test.ts` написаны, полный гейт агентом не подтверждён. Действие: `git merge wt/models` в ветку, прогнать `npm run check`, при красном — починить или откатить этот один коммит.
2. **Финальный `npm run check` на свободной машине.** Каждая пачка проходила гейт у своего агента, но при 4–6 параллельных агентах тяжёлые сторожа (`memory.test.ts` PERF-10/11, `demoBoss`, `demoDebugRun`, `[bench]` в render-ts) отваливались по таймауту 5 с и перепроверялись изолированно. На объединённом дереве полный прогон целиком без нагрузки ещё не делался.
3. **Слияние в `main` и push** — после зелёного гейта: `git checkout main && git merge claude/render-system-audit-41vi1o && git push origin main` (pre-push гоняет `npm run check` сам).
4. **Уборка воркtree**: `git worktree remove /home/user/wt/<имя>` для `stream-fog models terrain-water lighting-post vfx cursor-anchors` и удаление веток `wt/*` (локально и на origin) после слияния.
5. **Визуальная проверка в браузере** (`npm run demo`) — ни один агент не видел кадра: текстурирование арены (периоды слотов 6/4/5 — первая прикидка), градиент окружения и его ориентация (`Euler(π/2,0,0)`), тени на воде, наземные телеграфы, лента огненного шара, цвета команд из `game/demo-ts/app/presets/teams.json`, hit-flash. Аддон Blender (`tools/blender-addon`: кисть `_PAINT` и превью) проверен только `py_compile`.

## Открытые хвосты, названные агентами (не блокируют)

- REND-30: сценарий «Доля статики делит интенсивность между ярусами» сохранил старое имя (валидатор не даёт убрать сценарий в MODIFIED-блоке), тело говорит, что поля нет — переименовать отдельным чейнджем.
- BLND-14: sculpt-арены (BLND-13) канал `_PAINT` не несут — либо фраза в спеке, либо поддержка.
- Панель VFX редактора: список «добавить поле» — второй список ключей записи; вынести `EFFECT_FIELDS` из `assets-ts`. Составные поля (`radiusFromStat`, `colorAt`, `blink`) видны, но не редактируются.
- Отсечение VFX и `frameBudgetDeferrals` в эталонах нули: стенд бенча без камеры и без бюджета — намеренно (машинная независимость), но саму экономию эталон не пиняет.
- `engine/render-ts/src/index.ts` и `subsystems/lighting.ts` у потолка `max-lines` 400 — следующее добавление потребует выноса.
- Луч (`beam`) и флипбук в контенте дуэли не размещены: нет двухсущностной способности и атласа от художника.
- Камера наблюдателя не подключена к NTR-9-соединению наблюдателя (`observer-client-flow` — стаб).
- Ragdoll, WebGPU, SSAO — намеренно не делались (§4.4 отчёта). Из §4.2 не сделаны: остатки glTF (morph targets, второй UV/`aoMap`), запечённое освещение, KTX2; из §4.3 — растительность/ветер/погода, дальтонизм.
