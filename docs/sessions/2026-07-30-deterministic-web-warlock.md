# Разгон: Архитектура детерминированного веб-движка для Battle Royale (Warlocks-like)

## Дата
2026-07-30

## Тема / повод
Выбор технологического стека (Godot vs Unity vs Unreal) для браузерной потасовки и проектирование изолированного детерминированного ядра с поддержкой манипуляций временем (Rollback, замедление, перемотка реплеев).

## Что обсуждали
*   **Выбор движка:** Сравнили Godot, Unity и Unreal под веб-экспорт. Godot выиграл за счет минимального веса WebGL-сборки (3–5 МБ) и нативной поддержки WebRTC. Unreal полностью отброшен.
*   **Изоляция ядра:** Обсудили отделение Gameplay Core от рендера движка. Ядро оперирует только фазами матча (`MatchPhase`), полностью игнорируя сетевые концепции (комнаты, чаты) и стадии загрузки ассетов (экран загрузки рендерится внешним слоем на основе игровых фаз).
*   **Манипуляции временем:** Разработали детерминированное замедление всей карты и ультимейт «отмотки времени на 30 секунд» с интерактивным скроллингом таймлайна кастером (транслируется всем игрокам через сетевой ввод).
*   **Физика движка:** Разобрали переход от тяжелой физики к упрощенному кинематическому процессору (коллизии кругов, геометрические рикошеты снарядов по закону «угол падения равен углу отражения», затухание импульсов отталкивания Knockback).
*   **Тестирование через CLI:** Спроектировали концепцию Black-Box тестирования ядра через кроссплатформенный CLI (`stdin`/`stdout` JSON-потоки) для полной независимости тестов от языка реализации ядра.
*   **Тупики и отброшенные идеи:**
    *   *Идея:* Изменение глобального `DeltaTime` для замедления времени. *Отброшено:* Сломает детерминизм и замедлит кастера. Решено использовать ECS-компонент масштаба времени для каждой сущности отдельно.
    *   *Идея:* Пропуск тиков (Tick Skipping) для замедления объектов. *Отброшено:* Приведет к прохождению сквозь стены (Tunneling) и сломает расчет физики.
    *   *Идея:* Честный физический движок (Box2D/PhysX) со старта. *Отброшено:* Избыточно, усложняет детерминизацию. Заменено кастомным кинематическим процессором на Fixed-Point математике (16.16).

## К чему пришли
*   **Вывод 1** → Движок отображения — Godot Engine (WebGL/WebRTC). Выделенное детерминированное ядро пишется на C# или Rust (компилируется в WASM).
*   **Вывод 2** → Архитектура времени, кулдаунов и физики полностью переводится в тики с использованием Fixed-Point (16.16) арифметики без использования `float`.
*   **Вывод 3** → Реализация CLI-обертки для ядра обязательна для запуска Language-Agnostic тестов.

## Затронутые якоря
NET-1 (WebRTC Rollback), PHYS-2 (Fixed-Point Math), CORE-5 (ECS Architecture), REW-3 (Time Rewind / Snapshots), TEST-1 (CLI Black-Box)
